## 复现

从完整 Git 克隆运行 `tests/run_integration_checks.ps1`，生成日志/JSON 和截图于被忽略的 `build/` 目录。默认编译直接链接本仓库真实 Wave/Input/Sweep，不需工作区外的 AI 任务报告、开发 worktree 或旧 Wave 快照。

| CMake 选项 | 默认 | 用途 |
| --- | --- | --- |
| `LAB2_BUILD_BUSINESS_TESTS` | OFF | 额外构建隔离 ARM 测试 ELF，不混入正式固件 |
| `LAB2_ENABLE_INPUT_DEBUG` | OFF | 输入/扫频调试命令邮箱 |
| `WAVE_ENABLE_DIAGNOSTICS` | OFF | 显式输出测试命令邮箱 |

测试脚本开启独立测试目标，正常 Debug/Release 邮箱仍关闭；Diagnostic 才开启两种命令邮箱。默认固件保留只读诊断快照。

原资源哈希核对在原教学资源存在时执行；新克隆缺少这些可选资料时明确输出 SKIP，字模覆盖、适配约束及业务模型照常检查。

模块目录中的 DELIVERY、software_validation 等记录保留分支开发时点的数据；当前组合方式和最终状态以本文件及根 README 为准。
