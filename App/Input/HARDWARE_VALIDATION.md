# 输入与扫频上板验收步骤

2026-11-18：软件实现与受控测试已完成；用户确认当前没有外部输入、没有 PA8→PA1 回环。本文是待执行步骤，不是实测记录。共享板按主工程外 `ai_tasks/reports/hardware_schedule.md` 的 H01 排程交接；目前窗口尚未起算。先确认现场条件和输出方释放，再在获分配的时段使用 ST-Link。当前未烧录、复位或读取探针。

## 固件与查询入口

输入独立源使用自己 worktree 的 Diagnostic ELF，保留原菜单、游戏、秒表；没有真实业务 UI 接入，不以占位页验收屏幕响应。配置：

```powershell
cmake -S . -B build/Diagnostic -G Ninja '-DCMAKE_TOOLCHAIN_FILE=cmake/gcc-arm-none-eabi.cmake' -DCMAKE_BUILD_TYPE=Debug -DLAB2_ENABLE_INPUT_DEBUG=ON
cmake --build build/Diagnostic
```

默认 Debug/Release 的 `LAB2_ENABLE_INPUT_DEBUG=OFF`。打开后查询 `g_input_debug`：magic=0x494E5031，API=1。由调试器先写 command，再最后写一个与 acknowledged_id 不同的 request_id；后台恰好执行一次，读 acknowledged_id 和 command_result 确认。command：0=查询、1=新窗口、2=标准、3=扩展、4=扫频开始、5=扫频取消。普通独立源固件未链接 Wave，4/5 返回 BIZ_UNSUPPORTED，不能产生扫频 PASS。

`input` 给出状态、mHz、bp、原始周期/高电平计数、序号、窗口ID、采集起止/发布 tick、错误计数。单位为 1000 mHz=1 Hz、100 bp=1 个百分点。`capture` 给出 NDTR、IRQ/服务次数、游标重试/延后次数、故障及 DWT 周期最大值。只有 cycle_counter_available=true 才解释周期值；模块不启用或清零共享 DWT。若计数器未启用，安排单独计时，不能把 0 周期写成实测开销。

## 独立信号源接线

1. 断开所有可能驱动 PA1 的其他输出，确认没有 PA8 回环。核对排针第1针方向，再确认 JP4.23 是 PA1/TIM5_CH2；不使用 PA0/WKUP。只接一根信号线，不给 CH1 另接输入。
2. 独立源首测目标是方波 1 kHz/50%，在实际高阻负载下测得低电平约 0 V、高电平不超过 3.3 V。可用目标 3.3 Vpp/+1.65 V 偏置/High-Z 起调，实际仍须示波器确认低/高电平、过冲和偏置，不仅记录菜单值。
3. 明确示波器/信号源的高阻或50Ω设置及探头倍率。信号源地与开发板已确认的 GND 共地，再接源信号到 JP4.23。不能把仪器电源输出当作地，不接 RS-232 电平。
4. 记录实际开始时间、信号源型号和设置、示波器读数、共地与接线情况、输入提交SHA、ELF哈希及烧录日志。先保留现有可恢复固件，按 H01 窗口执行烧录与校验。

## 测量矩阵与恢复

- 标准频率：1、2、10、100、1000、10000、100000、200000 Hz；每点 10%、50%、90%，另补高频1%/99%。扩展增加250、400、500 kHz及333333/499258 Hz等非整除点，覆盖5%代表档位与窄脉冲。
- 记录原始 period_ticks/high_ticks、frequency_millihz/duty_bp、独立参考频率/占空比、窗口时间、发布序号、错误计数。频率误差为相对独立参考值的百分比，标准≤1%、扩展≤1%；占空比取百分点绝对差，标准≤2、扩展≤3。输入值不吸附输出档位。
- 每个频率上做双向频率/占空比跳变。1 Hz附近覆盖变化发生在上升沿前后、高电平中、低电平中等最坏相位，分别记源实际改变到采集完成、发布和屏幕显示的时间。最终屏幕≤2秒必须由真实UI接入后实测，不能用后端通过代替。
- 断开、重接、恒低、恒高：1500ms无新边沿后撤销VALID，不把常电平宣称为0%/100%。重接第一个不完整周期不发布；再次得到完整rise/fall/rise才有效。BeginWindow在高、低电平中调用，核对新ID没有使用调用前记录。
- 测低于1Hz、高于当前上限；观察OUT_OF_RANGE/NO_SIGNAL/ERROR的实际原因，不能把范围外或丢样混成正常读数。极低频无边沿足够久时NO_SIGNAL优先，不保证只靠无边沿区分静态与低频。
- 触摸全屏重绘、游戏运行、秒表、双PWM/SPWM并发时记录IRQ最大周期、游标延后、过捕获、DMA错误和有效更新间隔。500kHz半缓冲期限512μs、负载4MB/s仅是分析值，须实测DMA争用与ISR时间。异常必须立即撤销有效性并自动重获。

可在专用调试运行中注入 DMA TE、过捕获或延迟IRQ，检查ERROR及计数；不要在正常验收记录里把注入结果冒充自然硬件故障。每次注入后记录完整重获窗口。

## 真正回环扫频

先断开独立信号源，经总负责人确认真实输出提交后配置独立集成固件；检查固定输出源码哈希，禁止测试替身进入固件。PA8/TIM1_CH1→PA1/JP4.23，共地。B=PC7、SPWM=PA3，不因扫频停止。

1. 保存A的参数/开关、B和SPWM状态。用调试邮箱显式Start，十点为10、20、50、100、500、1000、5000、20000、100000、200000 Hz，50%占空比。
2. 核对每行实测来自对应 acquisition_id 的完整新窗口，频率误差≤1%；缺测或捕获错误不能PASS。扫频中手动改A应返回BUSY，B/SPWM继续；切页不取消。
3. 全部结束后检查原参数已真正applied、原开关已恢复、owner回MANUAL，然后才允许总PASS。分别以原A关闭、0%、100%、正常PWM起测。
4. 断线/部分失效、重复Start，在每个等待阶段Cancel，注入输出/采集故障及恢复超时。恢复成功的取消才是CANCELLED；恢复失败必须FAIL、restored=false，记录应急关断结果和实际owns_a，不能强制清掉占用标志。
