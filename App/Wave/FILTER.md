# 50 Hz SPWM 低通滤波与实测

PA3 / JP4.25 输出 3.3 V 单端 PWM，载波 20 kHz，400 点一周期，调制 50 Hz。默认调制指数 0.8，对应占空比 10%～90%。它含直流偏置，不直接驱动扬声器、线圈或其他功率负载。

## 一套可制作的两级 RC 电路

```text
PA3 ── R1 4.7 kΩ ──●── R2 4.7 kΩ ──●── OUT → 示波器高阻输入
                   │                │
                C1 100 nF        C2 100 nF
                   │                │
板 GND ────────────┴────────────────┴── 仪器 GND
```

R1/R2 用 1% 电阻，C1/C2 可用 100 nF 陶瓷或薄膜电容；记录容差。第一只电阻位于引脚和电容之间，限制边沿充放电电流，不能把大电容直接接 PA3。最坏 3.3 V/R1 约 0.70 mA 的瞬时电流，仍需按实际 MCU 电气条件和接线检查；输出只用于高阻观测。

单独一级 RC 的极点约 `1/(2πRC)=338.6 Hz`。两级无缓冲且元件相等，存在级间负载，不能把它当作两个互不影响的一级滤波器：理想高阻条件下

`H(s)=1 / (1 + 3sRC + (sRC)^2)`。

整体 -3 dB 频率约 **126.7 Hz**。50 Hz 幅度比约 **0.931**、相移约 **-24.4°**；20 kHz 幅度比约 **0.000286**，约 -70.9 dB。这是理想元件小信号计算，不是纹波实测值，也没有包括接线、输出电阻、负载或电容容差。

若实际高低电平为 3.3/0 V，平均值模型下直流偏置约 **1.65 V**；调制正弦峰值约 1.32 V，滤波后约 **1.23 V 峰值**（约 2.46 Vpp，中心 1.65 V）。实际幅度取决于引脚高低电平、元件、探头及负载。题目未规定失真数值，不据此承诺 THD 或纹波达标。

## 探头、接线和负载

- 断电搭建并核对 JP4.25=PA3 及地线；排针方向以实物为准。PA8/PC7 是另外两路 PWM，不与 PA3 短接。
- 示波器采用 DC 耦合、1 MΩ 输入，优先 ×10 探头并在仪器正确设置倍率；禁止在 OUT 开 50 Ω 终端，避免重载失真。
- 地夹接板 GND，使用短地线；不要把地夹接到 PA3 或 OUT。共享板上板/烧录与输入 AI 串行安排。
- 电路没有缓冲器；若要接外部低阻负载，需由总负责人另行审核缓冲/驱动方案，不直接降低 R 或并接负载补幅。

## 待执行的仪器记录

1. 输出默认关闭。使用诊断接口启动 SPWM；直接在 PA3 观测载波，约 50 µs 周期，占空比随 20 ms 调制周期变化。记录频率、峰峰值、低高电平和探头设置。
2. OUT 在 DC 耦合下用约 5 ms/div 观测，待 RC 启动暂态衰减后记录正弦频率、Vpp、平均值与最大/最小值。启动/停止的指数暂态是滤波器储能，不表示数字引脚没有关低。
3. 用合适时基和带宽观察载波残余，记录实测纹波峰峰值及测量带宽；若切换 AC 耦合测纹波，另记并保留 DC 偏置测量。
4. 显式停止后，PA3 应立即低电平；OUT 按 RC 时间常数衰减。重新启动从样本 0 开始，不连续拼接上次相位。
5. 同时运行双路 500 kHz、真实输入 500 kHz、页面/游戏，重复记录波形、DMA 错误计数及仪器配置。

本轮尚未制作该滤波器、接线或取得仪器读数。所有载波、模拟幅度、偏置、纹波及并发硬件负载项目均为待验。
