## 实机操作

1. 启动短暂显示红、绿、蓝、白色条，然后停留在“屏幕调试 T02”页。外侧双边框、八个边缘参考十字及中心十字用于观察方向与边界。
2. 首次未校准时先观察 RAW 原始采样；任意位置长按约 1.5 秒后松开，进入五点 RAM 校准。
3. 依次按住红色十字至少 0.1 秒后松开。点位需要稳定，过快/不稳定的触摸不会推进；目标点 30 秒未完成则超时。
4. 校准页任意位置长按 2 秒取消。失败、取消、超时均回到调试页，旧有效校准不被覆盖，可长按重试。
5. 成功后调试页显示“校准成功”。点击留下编号十字，拖动留下轨迹；显示原始值、屏幕坐标、按压状态和采样有效性。
6. “清除”清理标记和计数，“校准”重新校准，“菜单”进入中文主菜单。校准只存 RAM，断电/复位后需要重做。
7. 菜单可进入波输出、输入检测和秒表模拟页。波输出的频率/占空比按钮循环预设值；输入“信号”按钮切换有效/无信号/超时；模拟秒表支持暂停/继续、记圈、记段和最近六条记录。“记录”切换新旧三条。页面切换保留模拟状态。

电阻屏建议用触笔或指甲轻按。校准前没有可信的屏幕坐标，菜单按钮在校准成功后启用。校准时显示区域不应旋转或改变尺寸。

## 构建与文件

工程根目录执行 `cmake --preset Debug`、`cmake --build --preset Debug`；工具 bin 需先按总指挥转交报告加入 PATH。Release 使用同名 Release presets。

- `BSP/Screen/tftlcd.c`、`tftlcd.h`、`font.h`：HAL 显示工作副本。MMIO 为 volatile，保留题目绘图函数，去除旧 GPIO/FSMC 初始化及 printf；修复 ID 拼接及汉字查表。
- `BSP/Screen/touch.c`：由例程电阻触摸采样函数适配，五次去极值滤波、双批差值校验，无校准或存储副作用。
- `App/Screen/screen_app.c`：页面、事件、控件、诊断、RAM 校准流程和局部刷新。
- `App/Screen/screen_calibration.c`：五点仿射拟合，支持轴交换、镜像和偏移；误差超过 8 像素时拒绝新参数。
- `App/Screen/screen_selftest.c`：上电执行的七项校准算法检查。
- `App/Mock/`：明确标记为模拟的状态与操作，不产生真实波形或输入测量。

`ScreenApp_Init()` 在 GPIO/FSMC 初始化后调用一次；主循环调用 `ScreenApp_Process(HAL_GetTick())`。显示/触摸目标轮询间隔 8 ms，诊断/模拟字段最多每 100 ms 检查变化，不保证每次绘制都能在 8 ms 内完成。ISR 内不绘图，无完整帧缓冲。

## 字库及来源检查

工作副本统一 UTF-8。中文使用 Unicode 索引和 32×29、逐行、MSB 在前的静态字模；ASCII 沿用题目字库。`LCD_ShowFontHZ()` 在工作副本中接收 UTF-8，不应再传入 GBK 字节。

`BSP/Screen/tools/make_font.ps1` 从本机 SimSun 离线生成字模，`font_preview.png` 是字模核对图。生成工具不作为 MCU 图形库链接。`import_reference.py` 可复现显示工作副本，`verify_assets.py` 检查中文字模覆盖、116 字节长度及原始资源 SHA-256。

## 诊断与限制

`g_screen_diag` 位于 RAM，可用 ELF 符号通过 SWD 查看。magic 应为 `0x53435231`，stage=4 表示初始化完成，heartbeat 随主循环推进，LCD ID 为控制器读回值，selftest=`0x7f` 表示七项算法检查通过；它们不能替代肉眼显示和实际触摸验收。

T02 补回原例程 `TP_Init` 中不依赖 PEN 的首次 ADC 读取，D0/90 命令的 PD 位为 00，使采样完成后恢复 PENIRQ 检测；另在空闲期间每 200 ms 读取一次原始 ADC 供诊断，不将空闲读数视为按下。T01 遗漏该初始化且完全以 PEN 为采样门槛，实机未捕获到触摸；T02 烧录后已记录有效触摸样本和按压边沿。`g_touch_diag` 提供轮询、低电平样本、边沿、空闲探测、原始 ADC、有效/拒绝计数。调试页 `PEN:1` 表示未按下，`PEN:0` 表示按下；`OK` 表示有效触摸样本，`--` 表示当前无有效按压。

当前不含数字键盘、滑动条或任何真实业务模块。模拟秒表基于 HAL tick，仅用于页面交互展示；其毫秒数字不是真实秒表模块精度验收。圈记录为模拟累计时刻，段记录为距上次“记段”的间隔；重置清记录，满六条丢弃最旧一条。

首屏暂保留 ADC 命令 D0/90 与当前显示宏作为硬件适配起点，实际触摸控制芯片型号未读取。不要将“LCD 读回 0x9341”扩展成全部屏幕、触摸、方向和边缘精度已经通过。
